## Project scope

This repository contains static product documentation and support pages. Native iOS implementation is outside this website repository's scope.

## Local preview

With Python 3 installed, run this command from the repository directory:

```sh
python3 -m http.server 8000
```

Open `http://localhost:8000/`. These static pages do not require a build step.

## Maintenance

Check the current product behavior before changing feature or privacy statements. Verify App Store availability, pricing and trials against the current store listing and purchase screen. This README does not assert a release status or a relationship to another product name.
